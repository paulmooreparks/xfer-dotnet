# Legacy sample files

These are the 22 XferLang 0.x documents of the legacy repository, https://github.com/paulmooreparks/Xfer at commit `3f3d599` (2025-08-27), copied on 2026-10-21 for the differential test `TheLegacyRepositorysSampleFiles` (DESIGN.md section 12.6; the roadmap's milestone M2 asks for them). Each file is named for its path in that repository, with `/` written as `_`, so `examples/if-pi-demo/test.xfer` is `examples_if-pi-demo_test.xfer`.

A file ending in `.converted.xfer` is its 0.x original passed through `tools/fixtures/convert-legacy.mjs`, which handles the document head, `~true` and `~false`, and the `<"...">` and `<'...'>` wrappers, and refuses anything else that looks like 0.x. It converted 13 of the 22; the other 9 use processing instructions, dynamic elements or other 0.x constructs with no 1.0 form. None of the 13 converted files is a valid 1.0 document either: they keep 0.x processing instructions (`<! log ... !>`, `<! dynamicSource ... !>`, unclosed `<! ... !>` blocks, which 1.0 reports as `XFER0506`), tuples in parentheses (`XFER0103`), or nothing but processing instructions (`XFER0401`). The test does not expect them to be valid. It requires only that both CLIs say the same thing about every file, which, as 0.x and as near-1.0 text, is a good test of the two implementations' error paths.
